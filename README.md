# 신혼집 평면 모델러

노후 단독주택 리모델링을 위해, 추정 평면도와 현장 사진을 한곳에 모아 두고 실측하면서 맞춰 가는 웹 도구예요. 로그인 없이 링크만으로 여러 사람(가족, 설계사무소 등)이 함께 보고 고칠 수 있어요.

## 할 수 있는 것

- **1층·2층 평면**: 방을 사각형으로 그리고, 끌어서 옮기거나 크기를 바꿔요. 층별 면적 합계를 건축물대장 기준 면적과 비교해 보여줘요.
- **3D 보기**: 두 층을 쌓아서 돌려 보고, 사진 핀(원뿔)을 누르면 그 사진이 열려요.
- **사진 핀**: 사진을 고르고 평면을 한 번 누르면 찍은 위치, 한 번 더 누르면 바라본 방향이 저장돼요.
- **실측 반영**: 방에 실측 가로·세로를 넣으면 실측값으로 바뀌고(초록 테두리), 오른쪽·뒤쪽에 붙은 방과 핀도 차이만큼 같이 밀려요.
- **내보내기/불러오기**: 전체 데이터를 JSON 으로 저장하거나 다시 불러와요.

## 두 가지 모드

| 모드 | 조건 | 저장 위치 |
|---|---|---|
| 로컬 | `config.js` 가 비어 있을 때 | 각자 브라우저 (공유 안 됨) |
| 공유 | `config.js` 에 Supabase 정보가 있을 때 | Supabase (실시간 공유, 수정 이력 보관) |

## 배포 (GitHub Pages)

1. GitHub 레포 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿔요.
2. `main` 에 머지되면 `.github/workflows/pages.yml` 이 자동으로 배포해요.
3. 주소: `https://<GitHub 아이디>.github.io/<레포 이름>/`

## 공유 모드 켜기 (Supabase)

1. [supabase.com](https://supabase.com) 에서 무료 프로젝트를 만들어요.
2. **SQL Editor** 에 `supabase/schema.sql` 내용을 붙여 넣고 실행해요.
3. **Project Settings → API** 에서 `Project URL` 과 `anon public` 키를 복사해 `config.js` 에 넣어요.
4. 함께 쓸 사람에게 `https://.../?p=<프로젝트 키>` 링크를 보내요. 키는 아무 영문·숫자 조합이면 되고, 길고 추측하기 어려울수록 안전해요.

> 링크(프로젝트 키)를 아는 사람은 누구나 읽고 고칠 수 있어요. 사진은 비공개 버킷에 저장되고 1시간짜리 서명 URL 로만 보여요. 모든 수정은 `items_history` 테이블에 남아서 되돌릴 수 있어요.

## 사진

사진 원본은 공개 레포에 올리지 않아요. `seed/photos.json` 에는 사진 번호, 원본 파일명, 위치 설명만 있어요.

- 로컬 모드: **사진 파일 선택** 으로 원본 사진들을 한 번에 고르면, 파일명이 같은 사진이 자동으로 연결돼요 (그 브라우저에서만 보여요).
- 공유 모드: 같은 방법으로 고르면 Supabase 저장소에 올라가서 모두에게 보여요.

## 파일 구성

```
index.html, style.css, app.js   화면과 동작
store.js                        저장소 (로컬 / Supabase)
config.js                       Supabase 설정
seed/initial.json               처음 불러올 방·핀 데이터 (2026-11-21 손그림 평면도 기준)
seed/photos.json                현장 사진 50장 목록 (P01~P50, 촬영 시각 순)
supabase/schema.sql             Supabase 테이블·권한·저장소 설정
```

## 좌표 규칙

- 단위는 m. `x` 는 정면(도로)에서 봤을 때 왼쪽 → 오른쪽, `y` 는 도로 쪽(0) → 건물 뒤쪽.
- 핀 방향 `a` 는 도 단위, 0° 가 건물 뒤쪽을 바라보는 방향이고 시계방향으로 늘어나요.
